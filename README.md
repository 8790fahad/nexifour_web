# Nexifour Technologies Website

React + Vite corporate website for **Nexifour Technologies**.

## Run locally

```bash
cd /Users/mac/Documents/project/nexifour
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Pages

- `/` Home
- `/services` Services
- `/enterprise-software` Enterprise Software
- `/cybersecurity` Cybersecurity
- `/about` About Us
- `/contact` Contact Us

## Facebook page kit

See `facebook/PAGE_COPY.md` and open `facebook/cover.html` for a 820×312 cover mock.
